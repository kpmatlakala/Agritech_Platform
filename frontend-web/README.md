# AgriTech Web Dashboard

React + Vite admin dashboard for AgriTech Platform.

## Tech Stack
- React + Vite (TypeScript)
- Leaflet + OpenStreetMap (Maps)
- Axios (API calls)

## Setup

```bash
npm install
cp .env.example .env
# Fill in VITE_API_URL
npm run dev
Features
Farmer list view with search/filter

GPS map view (Leaflet)

CSV export for reporting
